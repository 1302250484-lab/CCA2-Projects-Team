## Project Description

This repository contains the group assignment for **Learning GitHub Repository & working alongside peers**.

### Files included:

1. **Traditional Programming vs Machine Learning**
   - `traditional_vs_ml.py`
   - Input Excel: `loan_applicants_input.xlsx`
   - Output Excel: `loan_applicants_output.xlsx`

2. **Hugging Face Sentiment Monitor**
   - `HuggingFace_Sentiment_Monitor.py`
   - Sentiment analysis using Hugging Face Transformers
   - Multiple problem statements included

3. **Retrieval Augmented Generation (RAG)**
   - `RAG_Example.py`
   - Simple RAG implementation with knowledge base + extra rules

## How to run the codes

1. Install required libraries:

```
pip install pandas openpyxl scikit-learn transformers torch
```

2. Keep all files in the same folder.

3. Run the programs:

```
python traditional_vs_ml.py
python HuggingFace_Sentiment_Monitor.py
python RAG_Example.py
```

4. `traditional_vs_ml.py` reads `loan_applicants_input.xlsx` and creates `loan_applicants_output.xlsx` automatically.
